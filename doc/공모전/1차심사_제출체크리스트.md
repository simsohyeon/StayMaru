## C. 제출 전 반드시 검증할 것 — OpenAPI 목록

운영사무국은 **제출한 인증키로 API 별 개발 기간(05.20~09.21) 호출건수와 서비스 내 활용 내역을 대조**합니다.
호출 이력이 없는 API 를 목록에 넣으면 "제출 내역 허위"로 평가 제외·수상 취소 사유가 될 수 있습니다.

공공데이터포털 마이페이지에서 **API 별 호출건수를 확인하고, 실제 호출 이력이 있는 것만** 남기세요.

> KorService2 는 지역기반·위치기반·키워드·공통/소개/이미지를 모두 쓰지만 활용신청은 하나다.

**확인 방법 — 아래 스크립트를 방화벽 없는 환경에서 실행하면 9종을 한 번에 판정합니다.**

```bash
TOUR_API_KEY='공공데이터포털 일반 인증키(Decoding)' \
  node doc/공모전/scripts/check-tour-apis.mjs
```

누적 호출건수는 공공데이터포털 → 로그인 → **마이페이지 > 오픈API > 개발계정** 에서
API 를 하나씩 열어 확인합니다(승인 상태·활용기간·일일 트래픽 표시).

> 미승인 API 는 앱이 graceful 폴백으로 기능만 숨기므로 화면상 티가 나지 않습니다. 반드시 포털에서 직접 확인하세요.
> 목록에서 빼야 할 항목이 생기면 슬라이드 11~12 를 다시 정리해야 합니다.

## D. 남은 작업 순서

1. **화면 캡처 21장** — `화면캡처_가이드.md` 대로 촬영 → 슬라이드 4, 6~10 삽입
2. **OpenAPI 호출건수 확인** → 슬라이드 11~12 목록 확정
3. **PDF 변환** — PowerPoint → 파일 > 내보내기 > PDF/XPS 만들기
   (맑은 고딕이 깨지지 않는지, 이미지가 잘리지 않는지 PDF 로 열어 확인)
4. 팀원 전원 회원가입 확인 → 콘텐츠랩 최종 팀원 입력
5. 인증키(인코딩·디코딩) 준비 → 제출
6. **웹·앱 구현 부문에도 지원했다면** 부문별 서류를 혼동하지 않았는지 확인 (오첨부 시 지원자 책임)
