### 6번 반려동물 — 기능은 정상, 호출 이력만 확인

코드 경로가 모두 살아 있다:
`constants/companions.ts` 에 `pet` 선택지 → `TripChatbot.tsx:593` 에서 렌더 →
`Home.tsx:261` 에서 `searchPetFriendlyPlaces()` 호출 → `KorPetTourService2/areaBasedList2`.

기능이 빠진 것처럼 보이는 이유: 반려동물 소스는 기존 후보 풀에 **추가만** 하고
결과를 반려동물 전용으로 걸러내지 않는다(`Home.tsx:255~261` 주석 — 전용 결과만 쓰면
취향 프로필이 통째로 무시되기 때문). 그래서 결과 화면이 눈에 띄게 달라지지 않는다.
또 서버 코스 생성은 반려동물·무장애 조건이면 `not-ready` 로 빠져(`api/course.ts:16`)
클라이언트 경로로 폴백하는데, 이 역시 사용자에게 보이지 않는다.

**위험 요소**: 개발 기간 중 동반자에서 '반려동물'을 실제로 선택한 적이 없으면
이 API 호출건수가 0 일 수 있다. 소개서에 남기려면 **마감 전에 반려동물 동반으로
코스를 한 번 생성**해 호출 이력을 만들어 두면 된다.

**확인 방법 — 아래 스크립트를 방화벽 없는 환경에서 실행하면 9종을 한 번에 판정합니다.**

```bash
TOUR_API_KEY='공공데이터포털 일반 인증키(Decoding)' \
  node doc/공모전/scripts/check-tour-apis.mjs
```

누적 호출건수는 공공데이터포털 → 로그인 → **마이페이지 > 오픈API > 개발계정** 에서
API 를 하나씩 열어 확인합니다(승인 상태·활용기간·일일 트래픽 표시).

> 미승인 API 는 앱이 graceful 폴백으로 기능만 숨기므로 화면상 티가 나지 않습니다. 반드시 포털에서 직접 확인하세요.
> 목록에서 빼야 할 항목이 생기면 슬라이드 11~12 를 다시 정리해야 합니다.
