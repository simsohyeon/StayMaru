# 제출자료 화면 캡처 가이드

`쉼마루_서비스소개서_v5.pptx` 에서 **텍스트는 모두 완성**되어 있고, 남은 작업은 이미지 21장을 자리에 넣는 것뿐입니다.
아래 순서대로 찍으면 슬라이드 순서와 1:1로 맞습니다.

## 촬영 환경 (모든 컷 공통)

| 항목 | 값 |
| --- | --- |
| 대상 | 배포본 `https://shimmaru.vercel.app` (실데이터가 보여야 함 — 목업 금지) |
| 화면 | 크롬 개발자도구 → 디바이스 모드 → **iPhone 14 Pro (393 × 852)** |
| 배율 | DPR 2 이상 (개발자도구 캡처 시 "Capture screenshot" 사용 → 786 × 1704 PNG) |
| 언어 | 한국어 (다국어 컷이 필요하면 `/settings` 에서 전환) |
| 정리 | 토스트·디버그 배너가 뜬 상태는 피하고, 로딩 스켈레톤이 아닌 **데이터가 다 찬 상태**로 촬영 |

> 캡처 전 `/settings` 에서 언어·테마를 한 번 고정해 두면 21장의 톤이 일정해집니다.

## 붙이는 방법

1. PPT 에서 `[화면 N 캡처]` 텍스트를 지웁니다.
2. 같은 셀에 이미지를 넣고 셀 너비에 맞춰 크기만 조절합니다(비율 고정).
3. 슬라이드 4는 대표 이미지 1장, 상세 이미지 4장을 각각 셀 안에 나란히 배치합니다.

> 21장을 이 파일명으로 모아 두면 한 번에 자동 삽입할 수 있습니다.
