# 제출자료 화면 캡처 가이드

`쉼마루_서비스소개서_v8.pptx` 는 **텍스트가 모두 완성**되어 있습니다. 남은 작업은 이미지를 자리에 넣는 것뿐입니다.

**찍어야 할 컷은 15장입니다.** (v7 기준 21장에서 6장 줄였습니다.)
대표 이미지(로고)는 촬영하지 않고 저장소 파일을 그대로 씁니다.

## 촬영 환경 (모든 컷 공통)

| 항목 | 값 |
| --- | --- |
| 대상 | 배포본 `https://staymaru.vercel.app` (실데이터가 보여야 함 — 목업 금지) |
| 화면 | 크롬 개발자도구 → 디바이스 모드 → **iPhone 14 Pro (393 × 852)** |
| 배율 | DPR 2 이상 ("Capture screenshot" 사용 → 786 × 1704 PNG) |
| 언어 | 한국어 |
| 상태 | **관리자 로그아웃 상태**로 촬영 (로그인 시 상단 메뉴에 「관리자」가 함께 찍힘) |
| 정리 | 토스트·디버그 배너가 뜬 상태는 피하고, 로딩 스켈레톤이 아닌 **데이터가 다 찬 상태**로 촬영 |

> 촬영 전 `/settings` 에서 언어·테마를 한 번 고정해 두면 15장의 톤이 일정해집니다.

## v7에서 줄인 것 (참고)

- 기능 흐름도를 **4칸 → 3칸**으로 줄였습니다. 흐름 설명도 3단계로 다시 썼습니다.
- 슬라이드 4 상세 이미지 **4장 → 3장**, 모두 다른 슬라이드 컷 재사용.
- `/course/map` 전용 컷, `/explore` 네 번째 컷, 장소 선택 순간 컷 등 **6장을 제거**했습니다.

## 붙이는 방법

1. 15장을 위 파일명 그대로 한 폴더에 모읍니다.
2. 그대로 올려 주시면 자동 삽입 스크립트로 자리에 넣어 드립니다.
3. 수동으로 하실 경우: PPT 에서 `[화면 N 캡처]` 텍스트를 지우고, 같은 셀에 이미지를 넣어 셀 너비에 맞춰 **비율 고정**으로 크기만 조절합니다.

> 한 슬라이드 안에서는 캡처 비율(모바일 세로 / 데스크톱 가로)을 섞지 마세요.
