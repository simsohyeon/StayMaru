## Codex 사후부검 — "탈락한다면 왜?" (2026-07-24)

### 유력 탈락 사유 (심각도순)
1. **기능 과잉으로 핵심 가치 흐림** — "꼭 써야 할 한 가지 이유" 부재. 기능 백화점 인상.
2. **데이터가 엔진이 아니라 화면 재료** — 데이터가 추천 결과를 어떻게 바꾸고 기존보다 뭐가 나은지 증명 없음. API 개수 ≠ 활용 역량.
3. **차별점 약함·복제 쉬움** — 통합검색+AI코스+다국어+숨은여행지는 흔한 조합.
4. **실사용·사업성 검증 없음** — 이용률·예약전환·방문유도 효과 근거 제로.
5. **데이터 품질·운영 현실 과소평가** — 누락/중복/폐업/번역 정제·갱신 불명확. 외부 예약링크 = 예약 아니라 이탈 링크.

### 심사위원 아픈 질문
1. 추천이 카카오맵/생성형 AI 결과보다 낫다는 **객관적 증거** 있나?
2. 한적지수·가중치 **산식과 검증**(방문 분산/만족도)은?
3. 반복 사용된 **핵심 기능·예약 전환 수치**는?

### Codex의 "하나만 고친다면"
> 기능 추가 멈추고, **'DataLab 기반 소외지역 분산 추천' 하나를 실제 데이터·수치로 입증**.
> 소외지역 포함률·코스 선택률·방문률·만족도 개선을 수치로.
